POS Control Buttons Access

Restrict POS actions using employee-level permissions.

POS Control Button Access allows you to manage refund and discount permissions in Point of Sale based on employee access rights. By configuring simple boolean options on the employee form, POS managers can control which employees are allowed to apply discounts or process refunds, improving security and operational control.

Key Features

  • Employee-level POS access control.
  • Refund and discount button restriction.
  • Simple and user-friendly configuration.
  • Improved POS security and control.
